# 社會科複習島

國中社會科（108 課綱）的 3D 島嶼複習網站。歷史、地理、公民共 9 座島、50 個章節，約 3,800 題。

公開網址：https://lutm6666.github.io/social-studies-review-island/

## 功能

- 9 座群島，每個章節是一座有代表模型的小島，島上有特色小人
- 題庫：精寫題、素養情境題、圖表判讀題（氣候圖、人口金字塔、產業結構），加上資料表生成的配對題與因果題
- 今日複習（間隔複習：答對後隔 1、3、7、14、30、60 天再出現）
- 錯題島：所有答錯的題目變成漂流瓶，可集中重練、依科目篩選
- 會考模擬（跨島混合計時）、題目搜尋
- 因果航線（臺灣史島）與跨科航線（小船往返各島）
- 小島隨答對題數成長、錯太多會起霧；全部章節小島都升級時，主島也跟著插上彩旗、點起燈籠、燃起聖火與金光環繞，並有升級徽章、彩帶、光柱與煙火慶祝，島名旁顯示星級
- 背景音樂（即時合成的輕柔旋律與海浪聲）與互動音效，可分別開關，右上角喇叭按鈕一鍵靜音
- 領航員導覽、天空依實際時間變化（也可固定白天／黃昏／夜晚）、省電模式、大字模式
- 介面可收合：左上面板可縮小、精簡卡片、右上眼睛按鈕（快捷鍵 H）只看小島；寬螢幕時卡片移到左側
- 進度備份：下載備份檔或複製備份代碼，到其他裝置匯入合併
- 每題解說旁有「回報錯誤」，會開啟已填好題號與內容的 GitHub 回報頁
- 可加到手機主畫面，第一次開啟後沒有網路也能複習

不出年份題與事件排序題。

## 使用

直接開啟 `index.html` 即可，不需要安裝。作答紀錄存在瀏覽器的 localStorage，換裝置前可用「進度備份」匯出；在 claude.ai 的 Artifact 版本中則會同步到帳號。

## 部署

整個資料夾是靜態網站，可直接放到 GitHub Pages 或 Netlify：

- **Netlify Drop**：把這個資料夾（或 `site.zip`）拖到 https://app.netlify.com/drop
- **GitHub Pages**：Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)`

## 開發

題庫與程式在 `src/`，修改後執行：

```bash
python3 build.py
```

會產生 `index.html`（一般網站用，含分享預覽與離線功能）、`sw.js`、`manifest.webmanifest`，以及 `artifact.html`（claude.ai Artifact 用）。

| 檔案 | 內容 |
|---|---|
| `src/app.html`、`src/app.js` | 介面與 3D 場景 |
| `src/deco.js`、`src/people.js`、`src/models_wip.js` | 裝飾、小人、章節模型 |
| `src/engine.js`、`src/dsl.js` | 題庫引擎與題目速寫工具 |
| `src/hand_twh_*.js`、`src/gen_twh.js` | 臺灣史島題庫 |
| `src/data_*.js` | 其他各島題庫、情境題、圖表題、補充說明 |
| `src/links_*.js` | 因果航線與跨科航線 |

題目由 AI 協助撰寫，未逐題對照教科書；發現錯誤歡迎開 issue。
