# 名詞與定義題誘答更新（待審查）

共 501 題。這類「X 指的是？」「Y 指的是哪一個？」的題目，原本誘答從同一組資料隨機抽，同一組裡常混著不同性質的東西（例如城堡、制度、地名混在一起），容易一眼排除。現在依主題分群，誘答優先從同一主題挑；同主題不足 3 個時才用其他資料補齊。

請逐題確認：
1. 誘答是否與正解同性質（同樣是人物、地方、制度、現象……），不會一眼排除。
2. 是否有誘答其實也能算正確答案。
3. 若仍有明顯不相干的選項，請指出。

回報格式：`題號｜問題｜建議修改`。

  - ✘ 制定國際貿易規範、處理貿易爭端的組織／聯合國下負責國際衛生事務的組織／二戰後成立、維護國際和平的政府間組織
- **eco6-g22** 「區域經濟整合」的意思是？
  - ✔ 鄰近國家降低關稅、加強經濟合作
  - ✘ 國與國之間的商品與勞務交易／以關稅等措施保護國內產業／政府對進口商品課徵的稅
- **eco6-g23** 「鄰近國家降低關稅、加強經濟合作」指的是？
  - ✔ 區域經濟整合
  - ✘ 全球化／保護主義／關稅
